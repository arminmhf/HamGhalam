# Frames: section headings, buttons and fixed messages

English sites have a fixed set of sections and buttons, and models translate them word for word. For each English frame, this file gives what a Persian site writes.

- ✍️ rows were chosen by a Persian copywriter (2026-10-01). Pick whichever option fits the tone and the product.
- 🔵 rows come from earlier team editing.
- The «نه» column lists the options the copywriter did **not** pick. Don't write them.
- Put the product name where «X» is.
